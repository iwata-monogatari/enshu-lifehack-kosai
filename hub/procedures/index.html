テーマ別に進む暮らし始めた新しい場所へ

暮らし始めた

布団・家具・大きなごみを、自分で持ち込むか、取りに来てもらうか決める。

布団や家具など通常の収集に出せない粗大ごみは、湖西市では戸別収集（電話予約制）と環境センターへの自己搬入の2つの方法から選べます。急いでいる、または費用を抑えたい場合は自己搬入が向いています。

提出先に出す証明書を、種類を間違えず最短で受け取る。

住民票、戸籍謄本・抄本、印鑑登録証明書など、提出先によって必要な証明書の種類は異なります。湖西市で取得できる主な証明書と窓口・手数料を整理しました。

近くの窓口に行ってから「ここでは扱っていません」を防ぐ。

湖西市の行政窓口は、吉美にある本庁と、旧新居町エリアの新居支所の2か所に分かれています。「どちらに行けば手続きできるか」を事前に確認しておくと二度手間を防げます。

詳しく見る →

犬の登録・鑑札の手続きを、出直しなしで一度に済ませる。

湖西市で犬を飼い始めたら、生後91日を過ぎた時点で登録が必要です。転入時にすでに登録済みの犬を連れてきた場合も、湖西市での登録の切り替えが必要になるので忘れずに手続きしましょう。

詳しく見る →

毎年の狂犬病予防注射を、忘れずに受けて注射済票までそろえる。

犬の登録が済んだら、次は毎年の狂犬病予防注射です。湖西市では動物病院での個別接種と、4月に市内を巡回する集合注射のどちらかを選べます。接種後は注射済票の交付を受けることが必要です。

引っ越し先で、ごみを間違えずに出せるようにする。

ごみ分別収集カレンダーは、引っ越し先の地区で「何を」「いつ」出せばいいかをまとめて確認できる資料です。湖西市はA地区・B地区で内容が分かれているので、まず自分の地区版を手に入れましょう。

詳しく見る →

引っ越し直後でも、明日のごみを正しく出せるようにする。

湖西市のごみ出しは地区（A地区・B地区）によって収集曜日が異なります。引っ越し直後で分からない場合は、まず自分の住所がどちらの地区か、収集カレンダーで確認しましょう。

詳しく見る →

引っ越してきた後の手続きを、抜けなく順番どおりに片づける。

湖西市に引っ越してきた後は、住所変更以外にも国民健康保険、マイナンバーカード、ごみの出し方、水道など、片づけるべき手続きが複数あります。優先順位を決めて、抜けなく進めましょう。

詳しく見る →

引っ越しの住所変更を、転出証明書から順番どおりに片づける。

湖西市で住所を変更するときは、転入届・転出届・転居届のどれに当てはまるかをまず整理しましょう。市外から湖西市に移る「転入」は、住み始めてから14日以内に市民課または新居支所へ届け出る必要があります。

詳しく見る →

マイナンバーカードを、申請から受け取りまで迷わず進める。

マイナンバーカードは転入時の各種手続きや証明書のコンビニ交付でも使うため、早めに用意しておくと便利です。湖西市では申請方法が複数あり、交付は市役所窓口で受け取ります。

詳しく見る →

犬や猫がいなくなった。最初の電話を、いますぐ正しい先へ。

飼っている犬や猫がいなくなったときは、まず落ち着いて連絡先を確認しましょう。湖西市環境課だけでなく、犬の保護は静岡県西部保健所が担当している場合が多いため、あわせて連絡するのが確実です。

詳しく見る →

車に頼らない日の移動を、バス・お助け号・電車で乗りこなす。

湖西市で車に頼らずに移動する場合、市が運行するコミュニティバス「コーちゃんバス」が主な選択肢です。JR駅と各地区の病院・買い物施設を結んでおり、市内は一律運賃で利用できます。

詳しく見る →

会社や学校に出す住民票を、急ぎでも確実に手に入れる。

会社の入社手続きや学校の提出書類で住民票の写しが急ぎで必要になることはよくあります。湖西市では窓口交付のほか、マイナンバーカードを使ったコンビニ交付や郵送請求も利用できます。

詳しく見る →

毎月の水道・下水道、仕組みと払い方を一度で見渡す。

湖西市の水道料金・下水道使用料に関する問い合わせは、湖西市上下水道課ではなく「お客さま料金センター」が窓口です。このセンターは豊橋市上下水道局と共同運営されており、電話番号が豊橋市の市外局番（0532）である点に注意してください。

詳しく見る →

引っ越し日に水が出ない、を防ぐ。水道の届け出を2営業日前までに。

引っ越し当日に水が使えないと困るため、水道の使用開始・休止の連絡は早めに済ませておく必要があります。湖西市では希望日の2営業日前までに「お客さま料金センター」へ連絡する仕組みです。

新しい場所へ

転出前の片付けは、粗大ごみ・持ち込み・処理不可品を分ける

湖西市の粗大ごみは廃棄物対策課への事前予約制の戸別収集が基本で、収集してもらえない大量の不用品や家電リサイクル対象外品は環境センターへの自己搬入も選べます。転出前は日程に余裕を持って予約しましょう。

詳しく見る →

犬の登録変更は、転出先自治体での手続きも見越して確認する

犬を飼っている世帯が湖西市外へ引っ越す場合、湖西市での登録を転出先自治体へ引き継ぐ手続きが必要です。湖西市で交付された鑑札と狂犬病予防注射済票を必ず持参し、転出先の窓口で登録変更を行いましょう。

詳しく見る →

転出届は、引っ越し先と届出方法を確認してから進める

湖西市の転出届は市役所市民課または新居支所市民窓口係で受け付けています。マイナンバーカードを持っていればマイナポータルからオンラインで提出でき、引っ越し前の来庁を省略できるのが特徴です。

詳しく見る →

湖西市から引っ越すときは、転出届と暮らしの停止手続きを一緒に確認する

湖西市から引っ越すときは、市民課での「転出届」と、水道・ごみ・学校/保育園・ペットなど「暮らしの停止手続き」を並行して進める必要があります。窓口が担当課ごとに分かれているため、チェックリスト形式で漏れなく確認しましょう。

詳しく見る →

子どもの転出は、学校と園の手続きを別々に確認する

子どもが在学・在園中に湖西市外へ転出する場合、小中学校は学校教育課、保育園・こども園は保育幼稚園課とそれぞれ窓口が分かれています。転出が決まったら早めに両方へ連絡し、必要書類を確認しましょう。

詳しく見る →

水道の中止は、使用をやめる日と精算方法を先に決める

湖西市の水道は上下水道課が運営していますが、使用中止・開始などの届出窓口は「お客さま料金センター」という、豊橋市上下水道局と共同運営する専用窓口が担当しています。電話番号が053ではなく0532（豊橋市外局番）になっている点に注意してください。
